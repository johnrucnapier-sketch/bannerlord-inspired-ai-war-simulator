# 第四种训练形式：八国真实地图对抗 · v0.7.0

独立的多国战略训练基线，供对手策略接入、规则测试与对抗实验使用。默认八国同图，有 **120 个据点（53 城镇、67 城堡）、273 个村庄、73 个家族、146 支领主部队**。地图和初始资源不对称。本项目是战略研究模拟器，不是骑砍 Mod，也没有完整复刻原游戏或参考 Mod 的自动 AI。

本目录独立安装，不覆盖前三种训练形式或历史版本。默认 realmap 对手仍为 `vanilla_v1`，旧版 `duel` / `rural` 的默认策略不变。当前候选源码已在固定依赖的独立环境通过干净公开导出的核心测试、适配测试与八进程短局检查。原 r7 的中断前缀已重建核验，原版续跑和从第 632.5 天切换候选源码的分支均已运行至第 840 天，两条后段完整重放及前后衔接核验通过。候选分支只运行了最后 207.5 天，不是候选源码从种子开始的完整 840 天比赛。公开文件按清单冻结，1/2/4 并发的同种子 21 天测量已完成；实际 Windows/远端 CI 验收仍待执行。这些调试与兼容性结果不证明国家、文化或策略强弱。

公开包支持重跑当前源码的新局和回归测试；不分发历史私有检查点与原始日志，因此不能只凭公开包精确复现上述第 632.5 天分支。完整证据范围与公开复现边界见 [VALIDATION.md](VALIDATION.md)。

## 训练范围

- 西、北、南帝国，库赛特，巴丹尼亚，瓦兰迪亚，斯特吉亚，阿塞莱；可选择其中 2–8 国。
- 每国独立观察、历史情报、指令权限和策略进程。主机先生成同一决策时刻的全部私有快照，再接收和应用命令。
- 所有国家自由混战。第三国是独立交战方，伤害按共同快照计算。
- 同家族军团，及国王/指定元帅接纳弱族最强一队的有限例外。不同家族军团独立携粮、移动、集结和协同。
- 实体民兵动员。人口、健康民兵、口粮和传令兵均从实际来源扣除；传令、集结、参战和返乡需要物理移动，没有货币系统。
- 失去全部城镇/城堡的国家在小时末灭亡，其家族按固定种子分别随机转投存续国家；不继承旧国历史视野。
- 六文化特性可开关。`culture_basis="owner"` 是当前默认实现假设，`"origin"` 可按来源文化计算，尚非最终确认的文化归属规则。
- 外交只有禁用的扩展接口，本版没有议和、结盟或外交策略。

## 安装与八进程短局

建议使用 Python 3.12。包声明最低 Python 3.10，其他版本需自行运行验证。本次干净公开导出在 Linux 的独立虚拟环境使用 Python 3.12.14 与声明的固定依赖 websockets 15.0.1，完成 313 项核心测试（311 项执行通过、2 项历史材料缺失跳过）、38 项适配测试和 SDK、保存/加载、重放、八进程及公开 CLI 冒烟。实际 Windows 执行仍待验证。无界面比赛不需要 GPU、原游戏或 Godot。每个基线使用独立虚拟环境，避免导入另一版本的同名 `aiwar` 包。

从仓库根目录进入本目录：

```sh
cd training/realmap-v0.7.0
python -m venv .venv
```

macOS / Linux 激活：`source .venv/bin/activate`。Windows PowerShell 激活：`.venv\Scripts\Activate.ps1`。然后在同一终端执行：

```sh
python -m pip install -e .
python ../../tools/verify_training_v070.py
python tools/play.py --days 3 --seed 1 --output runs/eight-nations-smoke
```

`tools/play.py` 为八国分别启动一个 `vanilla_v1` JSONL 进程，每 3 游戏小时决策一次。默认每次决策回复预算 2 秒、最多 100 条命令；主机每步检查状态。输出目录必须不存在，不能覆盖旧记录。三天只用于接入检查。省略 `--days` 使用默认 **840 天（每年 84 天）** 时限。

独立源码包须保留仓库式目录布局，并包含公开清单及 `tools/verify_training_v070.py`。文件哈希校验不是规则或策略测试。

更短的进程内检查也可运行：

```sh
python -m aiwar --mode realmap --days 1 --seed 1 --check --output runs/in-process-smoke.json
```

这条命令不是外部策略进程隔离测试；`--check` 在该 CLI 中每日检查状态。JSONL 比赛产生逐国请求/回复、命令回执、错误/超时、最终状态和配置/源码哈希。**私有观察是字段隔离，不是强对抗性保密或恶意代码安全沙箱。** 全局递增实体 ID 可能泄漏分配活动，独立进程不限制文件、网络和系统访问。详见 [接口边界](AGENT_API.md)。

## 接入自己的策略

策略按 [AGENT_API.md](AGENT_API.md) 的 JSONL v1 协议运行，每个国家提供一个 argv 数组。使用 Python 主机 API 可避免不同终端对 JSON 参数的转义差异；两国、文化开关和八国自定义策略的例子都在该文档中。

[Dev19 多国适配](../../strategies/submissions/dev19_multinational_v070/README.md) 是可选实验策略，不替换默认对手。使用它时保留 `strategies/submissions/dev19_multinational_v070/` 配套目录；只安装核心包不会自动安装这项策略。

## 观察界面

安装 Godot 4，导入 `godot/project.godot`。另开已激活本版虚拟环境的终端，在本目录运行：

```sh
python -m aiwar.server
```

界面可切换全知观察者与八个国家视角。国家视角不发送全知兵力总计或全局事件。保留配套策略目录时可选“Dev19 家族军团适配版”，各国使用独立进程，启动前核验适配源码哈希；缺少策略时该选项隐藏。当前仅完成 headless 状态与入口测试，未完成交互、视觉或导出包验收。
