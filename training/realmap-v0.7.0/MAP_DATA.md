# v0.7.0 随包地图与家族数据

默认数据位于 `aiwar/data/west_north/`，二维底图位于 `godot/assets/`。目录名沿用历史布局，**本版默认运行八国，不再仅运行西/北帝国**。首次运行不需要原游戏、游戏 DLL、原始场景或另行下载地图包。

代码和报告中的 `cities` 包括城镇与城堡，合计 **120 个据点**。三个帝国共享帝国文化，因此八国对应六种文化。

可在新局配置 `nations` 为 2–8 个不同的上述王国 ID。只初始化所选国家的据点、村庄、家族和部队；国家整数 ID 按所选顺序重新编号，王国字符串 ID 与稳定的地理区域索引不变。导航仍保留全图陆路，周边无人陆地可用于绕行，没有海运。

## 数据文件

- `navigation.json`：原始游戏 XY 平面的导航顶点、面、地形类别、可通行标记与共享边连通。运行时坐标乘 1000；桥面与水面区别保留，忽略高低起伏及可通行地面的速度差。
- `settlements.json`：图标/城门坐标、城镇/城堡类别、村庄绑定、初始国家与家族所有权。实体移动使用城门坐标，图标位置可不同。
- `clans.json`：73 个家族的原始 ID、名称、王国、初始驻地及领地映射。名称与初始驻地已按来源数据核实。
- `clan_tiers.json`：73 个家族等级、等级数据来源、XML 哈希、队伍上限公式版本说明与初始统治家族核实方法。
- `MAP_MANIFEST.json`：本版八国运行计数与上述四个 JSON 文件的 SHA-256。
- `godot/assets/` 中 PNG：根据派生二维几何绘制，没有使用原游戏材质或截图。

## 等级、队伍名额与统治家族的来源

这里区分三类证据，不能合并写成“完整 1.5.6 DLL 已复验”：

1. **家族等级、名称与初始驻地：**原版 1.5.6 SandBox XML 数据核实。
2. **NPC 基础领主队名额公式：**1.5.5 提取的 `DefaultClanTierModel`，并与公开 1.5.3 源码交叉核对。tier <3 为 1 队，tier 3–4 为 2 队，tier ≥5 为 3 队。这是总队数，不另加家主队；不模拟 `TalentMagnet` 加成。
3. **初始统治家族：**1.5.6 `spkingdoms.xml` 的王国 owner 英雄与 `spclans.xml` 的家族 owner 英雄匹配。八个匹配结果恰好都以 `_1` 结尾；后缀只是当前场景结果，不是一般选王法则。本版没有动态选举或王位继承模型。

地图及归属是真实来源的派生数据，初始化兵力、粮食、人口和各项行为仍是模拟器设定，不代表原版初始兵力或完整游戏机制。

## 哈希与替换

运行时 `aiwar.real_map.map_hashes()` 对四个 JSON 文件逐一计算 SHA-256，并写入新局配置的 `map_data_hashes`。加载记录时会核对地图数据身份；替换导航数据后应重启进程，不能混用已缓存的旧网格。

```sh
python -c "import json; from aiwar.real_map import map_hashes; print(json.dumps(map_hashes(), indent=2))"
```

`AIWAR_MAP_DIR` 可显式指定另一套兼容地图包；普通运行无需设置。更换任何数据都会改变实验身份，必须另存配置和结果，不覆盖历史数据。`tools/make_test_map.py` 仍提供原创矩形测试图，但只有明确生成并指定后才会使用，不会静默替换默认真实地图。
