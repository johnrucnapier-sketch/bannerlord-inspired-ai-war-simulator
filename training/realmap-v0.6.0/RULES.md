# 真实地图规则 v0.6.0：补给、运兵、巡逻与缴获

2026-11-02，本地新局基线 `v0.6.0-logistics-patrol-loot`。只对真实地图新局启用；内部存档格式仍为0.1.6，完整规则身份以配置中的local_baseline及realmap_rules_v6为准。旧存档、旧配置回放、duel/rural和公开冻结目录均不升级。本目录是独立的新版本，不覆盖旧基线。

## 1. 运输口粮与混装

每城镇/城堡最多一支运输队，抽调50健康民兵，可另外带最多20名健康驻军。步骑组成保留，运输驻军属于实际可战斗兵员：普通兵战力2、民兵战力1；统一接受战斗伤亡、缺粮减员和伤兵恢复，分别记账。返程民兵归民兵、未交付驻军归驻军，不能互相转化。离城民兵仍占民兵上限，运兵不占民兵名额。

货粮上限2000单位，口粮另算。出发口粮为全队30天的野外口粮：50民兵150粮，50民兵＋20驻军210粮。因此满载混装队可以带2000货粮＋210口粮。当前不设兵员与货粮之间的重量换算；20兵和2000货粮可同时满载。口粮实际扣源城库存，货粮不足则按剩余库存装载。口粮耗尽仍可消耗货粮，延续原规则。

运兵只用于城际deliver任务，沿用友方陆路邻接和未被围城条件。运兵、回城领主抽调补员没有最低留守50人的限制，可抽空健康驻军；策略自己的留守决策不属于基础规则限制。目标驻军上限500，不能接收的兵随队返回。目的地失守/被围，携兵粮返航；家乡失守沿用友城改道/等待机制。伤兵和步骑组成在整个行程中保留。归城仓库或驻军满时，剩余物资/人员保留等待，不复制、不凭空删除。

接口中food使用千分之一粮食单位：

```json
{"type":"dispatch","city":"源城ID","destination":"友城ID","mission":"deliver","troops":20,"food":2000000}
```

`troop_type`可选`infantry`/`cavalry`；省略则按源驻军组成分配。`fetch`仍可取粮，货粮容量也不含口粮；fetch/supply不接受运兵。

## 2. 给移动部队/军团送粮

```json
{"type":"dispatch","city":"源城ID","destination":"领主部队ID或军团ID","mission":"supply","food":500000}
{"type":"supply","unit":"现有运输队ID","target":"领主部队ID或军团ID"}
```

新规则的supply是持续任务，不再只是一次近距离交接。现有运输队须先完成运兵，才可改派给军团；不改变其返航基地和名额。

- 存活友方目标在行军、围城、野战、解围战、攻城战中都可接受运输任务。
- 未交战或攻城准备阶段的围城方，可在1000内部距离内交粮；被围守方不通过此接口绕过封锁。
- 野战/解围战从准备阶段起不可交接；实际攻城开始后不可交接，即使攻城因解围暂停也不恢复。
- 交战时，运输队在通往目标的可通行路线距目标约1500内部距离处等待。若已在附近则原地等待；不会自动加入所服务军团的战斗，但仍可被敌军直接攻击。
- 每小时追踪友军位置和状态，战斗结束后靠近再交粮。按接收者当前容量依次交接，多个运输队不重复装载。
- 领队阵亡而军团仍存活，继续跟随存活成员；解散后跟随原目标/已记录的存活成员；全部消失或不再友方则返航。
- 目标满载后剩余货粮随队返航，不丢弃。目标因解散丢掉的军团超额粮食不会转移给运输队。

## 3. 军团携粮与主动丢弃

单队容量仍为30天野外口粮。军团暂用60天容量，按成员当前健康＋伤兵人数合计；`army_carry_days`为配置值。组建只增加容量，原有粮食原封不动，没有免费补粮。城市整补、运输交接或缴获才增加实际粮食。

解散后按各单队30天容量确定性分配现有粮食，超额直接计为损失。野外可主动丢粮后解散，恢复单队机动；不新增战中撤退能力，交战中仍不能解散。

```json
{"type":"discard","unit":"领主部队ID","food":100000}
{"type":"disband","unit":"军团任一成员ID"}
```

军团成员发出discard时从全军团现有粮食中按ID顺序扣减；不能丢弃不存在的粮食。

## 4. 地方巡逻队

每个城镇/城堡自动最多派一支25健康驻军组成的巡逻队，抽调后必须至少留50健康驻军，即出巡门槛75。还须有30天出发口粮、不被围且有下属村庄。独立`patrol`类型，不占领主编制、不执行策略自由调兵命令。

按下属村庄ID固定顺序巡回，最后回城。存活兵及伤兵归驻军，休整24小时后重新判断出巡门槛，不在野外无中生有补齐。城内驻军被战略调走不会被巡逻门槛阻止。巡逻队受损、产生伤兵或粮食低于3天时提前回城；城池失守则寻找可达友城归队。

发现3000内部距离内的劫匪可攻击，包括正在袭击农民的劫匪。追击最多6小时，且目标及自身不能超出追击起点3000距离；超限回原巡逻路线，6小时内不重新发起追击，避免原地反复续追。巡逻速度1地图单位/小时；健康普通兵战力2，对匪沿用普通正规军倍率。不是对原版游戏机制的一比一复刻声明。

## 5. 缴获与村庄劫掠

领主/军团获胜后，可接收被消灭敌方领主、军团成员、村民运输队、军用运输队或巡逻队的剩余口粮＋货粮。按战后容量接收；共同获胜按单位ID依次分配，只生成一次战利品。超额粮食丢弃并统计；双方同归于尽无接收者。城外解围战同样适用，不直接掠取未被攻下城市的仓库。巡逻队、民兵、劫匪不成为这项新战利品的接收方。

村庄劫掠完成后，原有可掠夺存粮＋本次减少人口×1单位家庭口粮，按劫掠领主/军团容量接收。减少人口沿用原本40%损失与取整规则，不新增人口扣减。家庭口粮是单独的收益来源（`raid_food_generated`），不是把既有粮食复制一份；`raid_household_food=1000`为每减少人口对应的内部粮食单位，暂定可调整。原有停产一周和兵源损失规则不变。

## 6. 标识与观察

领主用旗帜，军团用大旗，巡逻用盾牌，民兵运输用带轮方车，农民运输用小方块；国家仍用颜色区分。混装队标“兵”，等待交接标“待”。详情展示运输驻军、伤兵、独立口粮与货粮；军团汇总当前粮食与容量。策略观察给出新规则身份、容量、运兵人数及己方可交粮状态；不公开不可见敌军的粮食库存。
