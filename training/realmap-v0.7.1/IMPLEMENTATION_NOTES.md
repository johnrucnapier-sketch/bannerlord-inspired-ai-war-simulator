# v0.7.0 实现边界与明确修正

本版将真实来源数据、参考机制、模拟器简化、策略启发式分开记录。目标是让规则可审计、策略可实验，而不是宣称复刻整个原游戏或参考 Mod。

## 机制对应

| 项目 | 本版实际范围 |
|---|---|
| 家族等级 | 1.5.6 SandBox XML 已核实，73 个运行家族 |
| 基础领主队数 | 1.5.5 DLL 模型并与公开 1.5.3 交叉核对；tier 分段 1/2/3 总队数，无额外家主队、无 TalentMagnet |
| 初始国王家族 | 初始王国 owner 英雄与家族 owner 英雄匹配；八国恰好为 `_1`，不模拟选举/继承 |
| 家族军团 | 通常同族，至少两支实际到场领主队；每族最多一个主军团 |
| 弱族援助 | 国王/指定元帅接纳满足条件的最强一队，保留无地例外；额外修正合法单名额家族无法自组军团的死角 |
| 跨族协同 | 独立军团/单队共同行动；不合并远方战力、物资或移动状态 |
| 动员人口 | 村庄当时在村人口的 20%，据点当时健康民兵的 70%，均向下取整 |
| 动员粮食 | 来源实际支付 `ceil(n/2)` 粮，1 粮 = 1000 内部单位；约 5 野外日，不采用参考文案的 10 天说法 |
| 动员传令 | 城堡 → 军团指挥官 → 家族集结点；集结点分别派往其他据点，各据点分别派往绑定村庄；每次本地支付 1 驻军 + 1 粮 |
| 队列移动 | 村 → 绑定据点 → 家族集结点 → 本族军团；到场才加入，返乡也需实际移动 |
| 集结等待 | 家族集结点收令起固定 72 小时；未模拟远方全到齐确认，因此不会自动提前结束 |
| 撤销传令 | 发令城堡直接分别派到来源节点和队列；明确的简化修正，未声称原样移植 Mod 撤销树 |
| 无接收对象撤销任务 | 实际队列、信使和征发任务结束且实际收令来源均已收撤销后，仅清理从未收令来源的未发出撤销任务；不改物理信号、资源或损失恢复 |
| 据点民兵损失 | 死亡容量占用按 180 天线性恢复；不会复活死者 |
| 费用 | 只有实体人粮，没有货币、工资、声望或影响力系统 |

## 不应误称为已完成的内容

- 完整英雄、雇佣家族、玩家家族、选王或动态元帅任命系统。当前元帅身份来自显式配置。
- 完整参考 Mod 自动家族准备和全国动员 AI。80%/主城驻军门槛用于弱族援助资格，但不是全部手动组军的前置条件；家族 72/240 小时、全国 4 军团上限、120/360 小时调度及所有原阈值并未全部按 Mod 强制执行。
- 完整消息确认协议。实体传令有真实成本、路线和到达，但没有为“所有远方来源已收到并已到齐”建立确认回传树。
- 原游戏政治/投奔概率。灭国后独立等概率转投是本基线的明确假设。
- 外交决策。当前所有国家自由混战，只有禁用的未来能力接口。
- 文化专属兵种树、海战、地形高度或完整原游戏经济。

`vanilla_v1` 和独立 Dev19 适配使用观察驱动的组织辅助层，具体触发条件见 [STRATEGY.md](STRATEGY.md)。合法手动命令保留策略自由，不能拿某一策略的行为当成引擎硬规则。

当前候选修正了辅助层给已有主军团的家族再组第二个主军团的问题，仍保留合法的余队独立行动和跨族援助。另修正历史动员记录因从未收令来源的未发出撤销任务而无法收尾的问题；真实单位、在途信使、已收令来源的撤销送达和 180 天损失恢复仍是完成约束。

这两项修正晚于 r7 的第 632.5 天中断点。原源码续跑与从同一检查点切换候选源码的分支均已运行至第 840 天，后段完整重放及前后衔接核验通过。候选只参与最后 207.5 天，前缀仍是原源码；两条路径必须分别记账，不能将旧前缀称为候选源码从种子开始的验证。当前已审查策略每轮重新构建规划器，续跑没有恢复任意策略的隐藏进程状态；不能由此保证其他有状态策略也可相同续跑。

候选后段把 `mob14949` 的六项未发出、从未收令来源的撤销任务标为过期，记录得以结束；原版仍有六项待发任务。该现象不代表成功返乡或取消真实损失恢复，候选终局另一个撤销中记录仍保留 54 条损失恢复账。历史私有检查点和原始日志不随公开包分发，公开代码可重跑新局和回归测试，但不足以精确复现该检查点分支，详见 [VALIDATION.md](VALIDATION.md)。

## 尚待确认的文化归属

默认 `culture_basis="owner"` 让特性跟随当前所有国；`"origin"` 使用来源国元数据。两种都可运行，但默认选择是实现假设，尚非最终确认的文化归属规则。应将此字段写入实验配置，不把两者混为同一条件。

## 灭国处理假设

在小时末统一判断零城镇/城堡国家，同一小时的灭亡者共享存续接收国集合。每个家族用种子、小时与原始家族 ID 独立决定去向，保存/加载可复现，不依赖国家遍历顺序。

转投保留真实单位、人粮与原位置。为避免旧阵营关系留在交战状态中，所有触及转投单位的战斗及关联围城/解围链安全取消，不追加胜负、伤亡或战利品；有关军团解散。该做法优先保证一致性，不等价于完整战时叛变系统。接收国不继承旧国历史视野，远处动员队列仍受原来源同国同族返乡限制。

## 实验与发布边界

- 本目录是独立 v0.7.0 基线，旧版本规则和实验成绩不自动适用。内部 `version: 0.1.6` 仅为兼容标记；实验须记录 `local_baseline`、完整配置和源码/地图哈希。
- 开发修订的短局统计只能说明对应源码与配置下的行为。不同修订、自然对局和构造机制场景必须分开报告。
- 本公开入口不依赖未分发的历史参考文档、私有日志或存档。验证通过范围和待完成项见 [VALIDATION.md](VALIDATION.md)，可执行检查使用随仓库提供的测试和校验工具。
- 私有观察提供字段级信息隔离，但全局递增实体 ID 可能泄漏分配活动，未提供强对抗性不可推断保证。独立策略进程和错误清理不构成文件、网络或操作系统沙箱。评测不可信策略需要额外安全隔离。
- Godot headless 与策略入口测试不代表已完成交互、视觉或导出包验收。
