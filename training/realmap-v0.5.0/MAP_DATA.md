# 随包地图数据

v0.5.0已经包含我们生成的西北帝国战略地图所需数据和底图，首次运行无需导入原游戏或另外下载地图包。默认路径aiwar/data/west_north，底图位于godot/assets。

- navigation.json：原始游戏XY平面导航顶点、面、地形类别、可通行标记与共享边连通。保留桥面与水面区别，忽略高低起伏及可通行地形的速度差。
- settlements.json：图标/城门坐标、城镇/城堡标记、村庄绑定及所属国家/家族。
- clans.json：国家、家族及初始驻地。
- PNG底图：根据上述二维几何生成，未使用原游戏材质/截图。

源导出包含西、北、南帝国与库赛特数据；当前realmap只初始化西/北两国（29据点、63村、18家族），不产生其他国家单位。导航保留全地图陆路，周边无人陆地仍可绕行；没有海运。

三份JSON保持本地已验证的数据字节及坐标，不因发布而重新缩放或排版；其SHA-256记入MAP_MANIFEST.json、发布冻结清单及每局配置。可用现有导入工具校验另一个包，但更换数据会改变评测身份，不覆盖原数据或混用成绩。

AIWAR_MAP_DIR可显式指定其他地图包；普通运行不需要设置该环境变量。tools/make_test_map.py仍保留原创矩形测试图，只有显式生成并指定它才使用，默认绝不会以假地图替代本张真实地图。

来源及许可边界见[DATA_NOTICE.md](aiwar/data/west_north/DATA_NOTICE.md)。
