# 西帝国 dev19：阶段性统一策略

适用冻结真实地图 realmap-v0.6.0，固定扮演西帝国 nation0。运行入口为 agent.py，版本 western-empire-v1-dev19。源码 SHA256：92549e49a7be8f721411048c549c3a804ff9249865902d300b46cdeec5f8b1b3。

## 使用

在完整模拟器仓库根目录，以 Python3.12+ 运行：

```sh
PYTHONPATH=training/realmap-v0.6.0 python training/realmap-v0.6.0/tools/play.py \
  --blue-command '["python", "strategies/submissions/western_empire_v1/agent.py"]' \
  --red vanilla_v1 --days 840 --seed 2700007 --output runs/western-2700007
```

输出目录必须不存在。正式JSONL每次决策默认2秒。依赖仓库同版本公开导航与 LogisticsPlanner；无需GPU、权重、API密钥或外部网络服务。遵循仓库MIT许可及地图数据来源声明。

## 方法

- 集中持续主军，合计可见敌方军团和附近援军，不误判孤立小队。
- 用真实驻军补员；合法合并残编、释放家族名额，从后方恢复兵力。
- 残军和援军共享固定友城集合点，避免互相追赶。
- 先侦察未知城防；追敌不能绕过攻城强度评估。
- 出征预算包括去程、战斗储备和到实际有粮友城的退路。粮不足先补粮，不被远方兵源诱走。

只使用正常己方观察和公开导航；不读取全知存档、敌方隐藏状态或未来随机数。没有更改规则、地图、现有策略或默认对手。“升级”指策略迭代和真实整补，不是引擎中不存在的经验等级。

## 当前验证

同一固定地图上的4个配对随机场景，不是8张独立地图。有限样本和两个固定对手的阶段性成功，不保证任意种子、任意未来对手统一。840天领地数获胜不计统一。详细当前结果见 REPORT.md。
