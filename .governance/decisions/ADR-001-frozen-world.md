# ADR-001: 冻结游戏、累积基础实验、独立迭代策略

- Status: Accepted
- Date: 2026-10-29

- At commit: 首次公开发布提交，以Git历史及v0.2.0标签为准。
- Shareable: yes

## 背景

世界规则曾随研究演进。若继续混合修改规则与策略，历史成绩难以比较；城市兵员入驻军机制变化后，旧护农曲线不能冒充新规则验证。

## 决策和后果

以最后一轮兵员直接入驻军、近满扩编、驻军归位的实现为v0.2.0。默认对手march固定，策略独立于本体迭代。原始数据、报告、配置及哈希保存；新实验追加新ID。真正必要的规则变动使用新基线及新成绩，不覆盖旧证据。

公开项目同时欢迎AI、程序策略和人工分析；不把任何已有策略标为全局最优。接口进程边界不等同于恶意代码安全沙箱。

## 取代关系

本记录建立首次公开冻结约定，不删除此前研究历史。
